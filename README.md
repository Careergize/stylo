# Stylo Gents Beauty Parlor — Mobile Web App

A luxury mobile-first web application for **Stylo Gents Beauty Parlor**, crafted with **React 19**, **Tailwind CSS v4**, **TypeScript**, and **Lucide Icons**.

Matches the attached 3-screen reference design:
- **Screen 1:** Welcome / Splash Screen with luxury brand monogram, hero photography, and "Book Appointment" pill button.
- **Screen 2:** Home Screen with Greeting, Location header, "New Client Special" Flat 20% OFF promo banner, Quick-select popular services grid, Upcoming appointment card, and Salon Highlights & Location card.
- **Screen 3:** Service Detail & Booking Screen with "Precision Haircut & Beard Sculpting" (₹350), stylist selector ("Akhil", "Vishnu" & "Hari"), horizontal interactive date chips, time slot chips, and sticky "Book Now" CTA with digital ticket pass & confetti confirmation.

---

## 🎨 Visual Identity & Theme
- **Background:** Deep obsidian matte black (`#0B0B0C` & `#121214`)
- **Card Surfaces:** Elevated dark charcoal (`#1C1C1E` & `#252528`)
- **Accent Color:** Warm caramel & gold gradient (`#E0A96D`, `#D4A373`, `#B88652`)
- **Typography:** Luxury Serif (*Playfair Display*) for headers, modern clean sans (*Plus Jakarta Sans*) for UI & body.
- **Border Radius:** Ultra-smooth rounded cards (`rounded-2xl`, `rounded-3xl`) and pill buttons.

---

## 🚀 Running Locally

```bash
# Install dependencies
npm install

# Start Vite dev server
npm run dev

# Build for production
npm run build
```

Open `http://localhost:5173/` in your browser.

---

## 📱 Desktop View Modes
The application includes a desktop header switcher:
1. **3-Screens Showcase:** Displays Screen 1, Screen 2, and Screen 3 side-by-side in realistic luxury phone mockups, matching the original reference screenshot layout!
2. **Interactive Phone:** Single interactive mobile phone simulator with dynamic island, bottom navigation bar, and live booking flows.
3. **Responsive / Fluid:** Adapts smoothly across any device or viewport size.
